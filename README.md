# Plane Poultry Panic

**[Play it in your browser](https://planepoultrypanic.mvdmakesthings.com/)**, or on [itch.io](https://mvdmakesthings.itch.io/plane-poultry-panic).

A 16-bit action game: you're a stranded passenger in an airport overrun by chickens powered up by magic mushrooms. You can't fight back, so you outsmart them with snacks, a fire extinguisher, luggage carts, the baggage carousel and good hiding spots, and try to catch the last flight out.

Click the game once so it gets your keyboard, then:

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | WASD or arrow keys | Left stick or D-pad |
| Run | Shift | Right shoulder |
| Use the selected item | Space | A |
| Switch inventory slot | Q / R or mouse wheel | LB / Y |
| Eat a snack | E | X |
| Interact (carts, doors, closets, cabinets) | F | B |
| Drop the selected item | G | Back |
| Pause | Esc | Start |

This repository only holds the exported web build, hosted on Vercel. Current version: v0.4.0, a playtest build; the art and music are first-pass placeholders.
